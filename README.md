This Privacy Policy explains how **SIRGUARD** (“SIRGUARD,” “we,” “us,” or “our”) collects, uses, stores, and protects information when you use the SIRGUARD Discord bot, website, software, and related services (collectively, the “Service”).

## 1. Information We Collect

SIRGUARD is designed to process only information reasonably necessary to provide its security and moderation functionality.

Depending on how SIRGUARD is configured and used, we may process the following categories of information.

### 1.1 Discord Server Information

SIRGUARD may process:

* Discord server ID.
* Server name.
* Server configuration information.
* Server security settings.
* Protected channels.
* Protected roles.
* Server snapshots or backup information.

### 1.2 Discord User Information

SIRGUARD may process information associated with Discord users when required for security functions, including:

* Discord user ID.
* Discord username or tag.
* Whether the account is a bot.
* Server membership information.
* Discord permissions relevant to security analysis.
* Information identifying the user responsible for an audited action.

SIRGUARD does **not** intentionally collect Discord users' passwords or Discord account authentication credentials.

### 1.3 Audit and Security Events

To detect potentially malicious activity, SIRGUARD may process security-related Discord events, including:

* Channel creation, deletion, or modification.
* Role creation, deletion, or modification.
* Member bans or kicks.
* Webhook creation, deletion, or modification.
* Other supported administrative or security events.

These events may be associated with the Discord user responsible for the action.

### 1.4 Security Incidents

When potentially malicious behavior is detected, SIRGUARD may create an incident containing information such as:

* Incident ID.
* Server ID.
* User ID.
* User name.
* Action involved.
* Risk score.
* Number of recent events.
* Incident status.
* Containment status.
* Relevant timestamps.

This information is used to analyze and respond to potential security incidents.
